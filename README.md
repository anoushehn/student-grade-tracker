# Student Grade Tracker

A Flask-based web application for tracking student grades and computing weighted averages.

## Features
- Add and manage students
- Add assignments with weights
- Enter and update grades
- Automatic percentage and letter grade calculation
- SQLite database (auto-created)

## Tech Stack
- Python
- Flask
- SQLite
- HTML / CSS

## How to Run
```bash
python -m venv .venv
source .venv/bin/activate
pip install flask
python app.py
